# Arsenal 2017/18 — план реализации

Входы: открытые Wyscout events/matches/players/teams, все 380 матчей АПЛ 2017/18. Исходное задание сохраняется.

1. Сохранить исходные архивы, версию GitHub и SHA-256; проверить состав лиги и 38 матчей Arsenal.
2. В ноутбуке проверить счёт, автоголы, пенальти, удаления, координаты, временные отметки и принадлежность игроков командам.
3. До расчётов зафиксировать H1: разницу непенальтийного xG-баланса; H2: разницу реализации (непенальтийные голы минус xG); H3: удары соперника после неудачной передачи за 15 секунд, с чувствительностью 10/20 секунд.
4. Обучить логистическую регрессию на ранних 80% матчей без Arsenal, проверить на поздних 20%; сравнить Brier/log loss с константой. Учитывать только предударные признаки.
5. Сравнить 19 пар соперников, бутстрэп 5000, seed 42, перестановочные проверки и Holm; проверить счёт, удаления, силу соперников и половины сезона.
6. Построить парные сравнения, карты ударов, xG, реализацию, риск после передач, калибровку и устойчивость. Все объяснения и рекомендации — в ноутбуке рядом с результатами.
7. Экспортировать единый JSON для статического приложения, PPTX и CSV. Интерфейс на русском, без CDN и внешних API, с реальными событиями и контрпримерами.
8. Создать 12 основных + 2 резервных слайда, заметки докладчика, сценарий на 13–15 минут, README и зависимости.
9. Чистый прогон ноутбука, проверки граничных случаев и данных; браузерная проверка без внешней сети; структурная и визуальная проверка каждого слайда.

Аналитика остаётся в notebook. Работа выполняется одним агентом. Команда и личные вклады не выдумываются. Отрицательные и неопределённые результаты сохраняются.
